# Fonte das Peitas Shop

Crie um e-commerce completo, moderno e profissional chamado “Fonte das Peitas”.

IMPORTANTE:

Quero que você tenha liberdade para criar o design, identidade visual, organização das páginas e experiência do usuário da maneira que considerar mais profissional.

Não copie literalmente nenhum layout específico.

Crie uma identidade própria, moderna e comercial.

O projeto deve ser desenvolvido como uma loja virtual REAL, e não apenas como uma landing page ou protótipo visual.

==================================================

ESTRUTURA PRINCIPAL

==================================================

Criar:

- Página inicial

- Página de produtos

- Página individual do produto

- Categorias

- Busca

- Carrinho

- Checkout

- Página de pedido realizado

- Página de pedido pendente

- Página de pedido com erro

- Login administrativo

- Painel administrativo

O site precisa ser totalmente responsivo, com prioridade para celular.

==================================================

DESIGN

==================================================

Crie o visual da maneira que considerar mais profissional.

Quero:

- Design moderno

- Aparência premium

- Boa hierarquia visual

- Animações suaves

- Excelente versão mobile

- Cards de produtos bem trabalhados

- Navegação simples

- Header profissional

- Footer completo

- Boa utilização de imagens

- Tipografia moderna

- Microinterações

- Estados de carregamento

- Estados vazios

- Mensagens de erro amigáveis

Evite aparência genérica de template.

O site deve parecer uma empresa real e pronta para vender.

PRODUTOS

==================================================

Criar um sistema completo de produtos.

Cada produto deve possuir:

- ID

- Nome

- Descrição

- Preço

- Preço promocional opcional

- Categoria

- Subcategoria

- Imagem principal

- Galeria de imagens

- Estoque

- Status

- Destaque

- Data de criação

- Data de atualização

O administrador deve conseguir criar, editar e excluir produtos.

Também deve conseguir:

- Alterar preço

- Alterar imagens

- Alterar descrição

- Alterar categoria

- Alterar estoque

- Marcar como destaque

- Marcar como esgotado

- Ocultar produto

- Reativar produto

Quando um produto estiver esgotado, ele deve continuar aparecendo na loja, mas não poderá ser comprado.

Permitir pesquisar pelo nome do produto e outros dados relevantes.

Filtros e busca devem funcionar sem precisar recarregar a página inteira.

Não entregue somente um protótipo.

2. Produto aparecer na loja

3. Editar produto

5. Marcar produto como esgotado
